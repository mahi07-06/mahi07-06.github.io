# mahi07-06.github.io

Personal portfolio of **Mahiraj Seervi**: robotic actuators, legged robots and manipulation.

Plain HTML/CSS/JS. There is no build step, so GitHub Pages serves the files as they are.

## Publish (one time)
1. On GitHub, create a new **public** repository named exactly mahi07-06.github.io.
2. Upload all files in this folder, keeping the folder structure. Use **Add file → Upload files** and drag the whole folder in.
3. Go to **Settings → Pages**. Under Source, choose **Deploy from a branch** with branch main and folder / (root), then save.
4. After 1–2 minutes the site is live at **https://mahi07-06.github.io**.

Until you add an image, its spot shows a labelled placeholder. The profile photo spot shows "MS" until you add a photo.

## Editing
- **Text:** edit index.html, projects.html, publications.html or ideas.html directly. On GitHub, open the file, click the pencil icon, edit, then commit.
- **Colors:** change --accent at the top of assets/css/style.css.
- **Before making the IISc report public,** check with your lab (see the TODO comment in publications.html).
